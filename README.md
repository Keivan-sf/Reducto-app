# Reducto

The Expo Go application lives in [Reducto-Frontend](./Reducto-Frontend/README.md). The backend is provided separately under `Reducto-backend` and should be running on port 3000.

```sh
cd Reducto-Frontend
pnpm install
pnpm dev
```

Open http://localhost:8081 for web or scan Expo’s QR code with Expo Go on Android. See the [frontend README](./Reducto-Frontend/README.md) for device networking, features, backend boundaries, and test commands.
