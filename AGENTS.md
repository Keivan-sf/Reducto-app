# Reducto

Reducto is supposed to be a Telegram clone.
Backend code is given as reference under ./Reducto-backend
Backend is running on http://localhost:3000 and you can access openapi.json on http://localhost:3000/openapi.json
There are some good information about backend on ./Reducto-backend/README.md make sure to read that

Try to find out about telegram designs (and use it's colors) before commitin to any design

I need you to build a cross-platform application that works on web, and android. I want you to write it using expo-go.
Make sure that you separate this repository into well chosen sections and make the code readable. write tests if possible.
Over all I need these pages:

1. Login/sign-up page
2. Main chat view
3. Settings(edit profile) page
